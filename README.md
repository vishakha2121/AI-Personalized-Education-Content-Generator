## 🌟 **Overview**

An intelligent learning platform that uses **Artificial Intelligence (Gemini API)**, **Knowledge Tracing**, and **Reinforcement Learning** to create completely personalized educational content for every student.

> **"One-size-fits-all education is outdated. Welcome to the future of personalized learning."**

---

## 🎯 **Problem Statement**

Traditional education faces several critical challenges:

- ❌ **One-Size-Fits-All Approach** - Same content for all students regardless of learning pace
- ❌ **Limited Personalization** - Cannot create unique content for 30+ students simultaneously
- ❌ **Knowledge Gaps** - Students struggle with fundamentals without intervention
- ❌ **Lack of Engagement** - Generic content fails to capture student interest
- ❌ **No Real-time Adaptation** - Teaching materials don't adjust during learning
- ❌ **Resource Constraints** - Creating personalized content is time-consuming and expensive
- ❌ **Different Learning Styles** - Visual, auditory, kinesthetic learners need different formats

---

## 💡 **Our Solution**

### **1. Intelligent Content Generation (Gemini AI)**
- 🤖 Automatically generates adaptive lessons based on student's knowledge level
- 📝 Creates personalized quizzes with varying difficulty
- 💻 Generates coding exercises tailored to programming skills
- 🎮 Produces interactive simulations for complex concepts
- 📊 Creates visual explanations (diagrams, charts, infographics)

### **2. Knowledge Tracing System**
- 📈 Tracks student's mastery of each concept in real-time
- 🔍 Identifies knowledge gaps and misconceptions
- 🗺️ Creates detailed knowledge maps
- 🔮 Predicts future performance on new topics
- 🧠 Uses Bayesian & Deep Knowledge Tracing techniques

### **3. Reinforcement Learning for Adaptation**
- 🎯 Learns optimal content delivery strategy for each student
- 📊 Adjusts difficulty levels based on performance feedback
- 🧭 Recommends next best learning activities
- ⚖️ Balances exploration vs. exploitation of topics
- 🚀 Maximizes knowledge retention

### **4. Multi-Format Content Delivery**
- 📖 **Text Lessons** - Adaptive reading materials
- 🎥 **Video Content** - AI-generated explanations
- 📝 **Interactive Quizzes** - Multiple choice, fill-in-the-blank, matching
- 💻 **Coding Exercises** - Real-time code editor with AI feedback
- 🎮 **Simulations** - Interactive models for complex concepts
- 📊 **Visual Explanations** - AI-generated diagrams and charts
- 🔊 **Audio Explanations** - Text-to-speech for auditory learners

### **5. Real-time Progress Tracking**
- 📊 Detailed analytics dashboard
- 📈 Performance metrics across subjects
- ⏱️ Time spent and learning efficiency analysis
- 🎯 Strengths and weaknesses identification
- 🚀 Progress predictions and recommendations

## 🧠 **AI & ML Models**

### **Knowledge Tracing**
- 🧬 **Bayesian Knowledge Tracing (BKT)** - Binary knowledge state tracking
- 🧠 **Deep Knowledge Tracing (DKT)** - Neural network pattern recognition
- 📊 **Item Response Theory (IRT)** - Student ability and question difficulty modeling
- 🔗 **Factorization Machines** - Student-question interaction capture

### **Reinforcement Learning**
- 🎯 **Q-Learning** - Optimal content selection
- 🎲 **Multi-Armed Bandit** - Exploring vs. exploiting content types
- 📈 **Policy Gradient** - Optimal teaching strategy learning
- 🏆 **Reward Function** - Maximizes learning progress and engagement

### **Natural Language Processing (via Gemini)**
- 📝 **Content Generation** - Lessons, explanations, and questions
- 📄 **Text Summarization** - Condensing complex topics
- ❤️ **Sentiment Analysis** - Understanding student feedback
- 💬 **Question Answering** - Interactive AI tutor capabilities
- 🌍 **Language Translation** - Multi-language support

## 🛠️ **Tech Stack**

### **Backend**# Navigate to backend
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Copy environment variables
cp .env.example .env

# Edit .env and add your Gemini API Key
# GEMINI_API_KEY=your_api_key_here

# Run the backend server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Edit .env and add your API URL
# REACT_APP_API_URL=http://localhost:8000

# Run the frontend server
npm start
